# AI Exam Question Generator App

A Vite + React application that generates exam questions with Gemini, supports quiz gameplay, chat, authentication, and history tracking.

## Run Locally

**Prerequisites:**
- Node.js 18+
- npm

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create your environment file:
   ```bash
   cp .env.example .env.local
   ```
3. Update `.env.local` with your Gemini and Firebase keys.
4. Start the app:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```
